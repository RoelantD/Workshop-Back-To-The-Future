# Introduction

Welcome to the Sports Prediction & AI Agent Workshop!

In this hands-on workshop, you'll learn how to build a machine learning model to predict sports outcomes and then use that model to power an intelligent betting agent. No prior experience with Azure Machine Learning Studio is required—everything is done with open-source Python tools and code you can run locally.

## What You'll Do
- Explore and clean real-world sports and weather datasets
- Build, train, and evaluate machine learning models using Python (pandas, scikit-learn, etc.)
- Automate your ML workflow with simple pipelines
- Deploy your trained model for real-world use
- Create an AI agent that uses your model to make predictions and place bets

## Who Is This For?
This workshop is designed for:
- Data science beginners and enthusiasts
- Developers interested in practical machine learning
- Anyone curious about AI-powered agents and automation

## Prerequisites
- Basic Python knowledge (variables, functions, etc.)
- A laptop with Python 3.8+ and Visual Studio Code installed

## Workshop Structure
1. **Part 1:** Build Your Sports Prediction Model
2. **Part 2:** Create and Deploy Your AI Betting Agent

Let's get started and have fun building together!
